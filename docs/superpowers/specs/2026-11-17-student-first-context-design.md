# Student-first context design

## Intent

Present PetriLab as a welcoming educational tool for students and make its authorship visible without competing with the learning task.

## Goals

- Explain immediately that the tool teaches process mining step by step.
- Credit Cristian Venegas / LuN4t!k0 and Claude as the team behind the project.
- Replace the outlined transparent headline with solid, high-contrast text.
- Remove decorative status indicators that do not represent actual application state.
- Increase the smallest instructional text and reduce background decoration.

## Non-goals

- Do not change the Alpha engine, lesson sequence, editor, validation, or simulator.
- Do not turn the page into a personal portfolio or add a large biography section.

## Approach

Keep the existing visual system and simplify it. Use a compact, solid headline; retain the concept map because it teaches the workflow; remove the fake top progress and local-data badge; and place a concise creator message with a GitHub link in the footer. A full visual redesign was rejected because it would risk the already validated teaching flow, while a footer-only credit would not give students enough context about the tool's purpose.
